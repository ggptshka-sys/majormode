# MajorMode — картинки гитарных аккордов

Программа для Windows: вы вводите аккорд, она рисует аппликатуру на грифе и сохраняет картинку в **GIF**, PNG или JPG. Картинку можно вставить в видео, например в REAPER, или отправить ученику.

Программа сделана для незрячего учителя гитары и полностью управляется с клавиатуры: все поля озвучиваются программами экранного доступа (NVDA, Экранный диктор). Зрячим пользователям она тоже удобна.

## Как скачать и запустить

Нужна Windows 10 или 11 (64-битная). Ничего дополнительно устанавливать не надо.

1. Откройте страницу [последней версии](https://github.com/ggptshka-sys/majormode/releases/latest) и скачайте файл **MajorMode.exe** из раздела Assets.
2. Положите файл в свою папку, например «Документы\MajorMode». Не кладите его в Program Files: иначе программа не сможет обновляться сама.
3. Запустите MajorMode.exe двойным щелчком или клавишей Enter.

При первом запуске Windows может показать окно «Система Windows защитила ваш компьютер» — программа не подписана платным сертификатом. Нажмите **«Подробнее»**, затем **«Выполнить в любом случае»**. Это нужно один раз.

Другой способ: перед запуском откройте свойства файла (Alt+Enter), отметьте «Разблокировать» и нажмите «ОК».

## Обновление

Нажмите **«Проверить обновления»** в нижней строке окна (Alt+Б). Если есть новая версия, программа спросит подтверждение, скачает ее и перезапустится сама. Автоматически ничего не скачивается.

## Как пользоваться

Поля идут сверху вниз в порядке клавиши Tab.

1. **Название аккорда** — любой текст: C, Dm, F#m7, Bb. Пишется крупно над грифом и подставляется в имя файла.
2. **Палец 1–4: лад и струна.**
   - Лад: от 1 до 24.
   - Струна: от 1 до 6.
   - **Баррэ на все струны** ставится первым пальцем: в поле «Струна» у пальца 1 введите латинскую **B**. Например, лад 5 и струна B — баррэ на 5 ладу на все шесть струн.
   - **Малое баррэ** — перечислите соседние струны через запятую, например `4,3,2`. Работает у любого пальца.
   - **Чтобы пропустить палец, введите 0 в оба поля.** Это не открытая струна: открытые струны рисуются сами.
3. **Заглушенные струны** — номера через запятую: `6` или `6,5`. Пусто или `XX` — заглушенных нет.
4. **Ориентация грифа** — вертикально или горизонтально. Переключается стрелками.
5. **Холст** — размер картинки: 16:9 (1920×1080), 9:16 (1080×1920) и те же в 4K.
6. **Стиль изображения** — схематичный, современный темный или деревянный. Меняется только оформление.
7. **Формат** — GIF (основной), PNG или JPG.
8. **Имя файла** — по умолчанию берется из названия аккорда. Ниже видно, с каким именем файл будет сохранен.
9. **Текущий путь** и кнопка **«Выбор пути»** — папка, куда сохраняются картинки.
10. **Сохранить** (Ctrl+S). Если такой файл уже есть, программа спросит, перезаписать ли его.

Ошибки ввода показываются рядом с полем и озвучиваются после короткой паузы. Справа от картинки — **Описание аккорда**: полный текст того, что нарисовано. Его удобно прочитать программой экранного доступа, чтобы проверить аккорд.

В нижней строке окна — состояние картинки (например, «Сохранено: C.gif») и последнее сообщение. В NVDA ее читает команда NVDA+End, в Экранном дикторе — Диктор+End.

### Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| Ctrl+S | Сохранить |
| Ctrl+O | Выбор пути |
| Alt+1 … Alt+4 | Поле «лад» пальца 1–4 |
| Alt+Н | Название аккорда |
| Alt+З | Заглушенные струны |
| Alt+В / Alt+Г | Вертикально / Горизонтально |
| Alt+Х | Холст |
| Alt+Л | Стиль изображения |
| Alt+Ф | Формат |
| Alt+И | Имя файла |
| Alt+П | Выбор пути |
| Alt+С | Сохранить |
| Alt+О | Описание аккорда |
| Alt+Д | Поделиться: открыть эту страницу и скопировать ссылку на нее |
| Alt+Б | Проверить обновления |

Буквенные сочетания работают в русской раскладке. Alt+цифры, Ctrl+S и Ctrl+O — в любой.

## Что на картинке

- Пальцы — кружки с цифрой: 1 красный, 2 оранжевый, 3 желтый, 4 зеленый.
- Баррэ — полоса через все струны с цифрой 1. Малое баррэ — полоса цвета пальца только на указанных струнах, с номером пальца.
- Заглушенная струна — X у начала струны, открытая — кружок O.
- Слева от грифа (или под ним в горизонтальной ориентации) — номер первого показанного лада. Программа сама выбирает, какие лады показать: обычно пять, максимум семь.

Программа запоминает папку, ориентацию, холст, стиль и формат. Сами аккорды не сохраняются.
