# Agent Log

## 2026-11-07
- Старт проекта. Папка была пустой. Установлен .NET SDK 10.0.403 (LTS) в `~/.dotnet` на macOS агента.
- Решение: рендер на SkiaSharp 4.155 (MIT) вместо WPF DrawingContext — тестируемость вне Windows и единый renderer для превью/экспорта.
- Решение: собственный GIF-кодер (качество палитры WIC слабое, ImageSharp — Split License).
- Core: модель, парсер (0/0, B, mute-токены), авто-диапазон ладов, геометрия, описание, санитизация имен, настройки. 109 тестов зеленые (macOS).
- Пользователь дал репозиторий https://github.com/ggptshka-sys/majormode (пустой). Примеры картинок агент делает сам.
- Rendering: 3 стиля, общий код маркеров; GIF-кодер с тестовым независимым декодером. Раскладка: название+схема центрируются блоком (фикс пустоты на 9:16).
- App: MVVM, UIA Notification для объявлений (fallback LiveRegion флагом), debounce превью 150 мс / описание 700 мс / ошибки 1,5 с, настройки в %LOCALAPPDATA%.
- Итого 146 тестов зеленые на macOS; WPF только компилируется.
- Push в GitHub. Первый CI на Windows упал на 1 тесте: Segoe UI дает больше полутонов → дизеринг шумел по краям цифр. Решение: GifDither.Auto (дизеринг только при средней ошибке > 0.1; плоские стили ~0.01, дерево ~0.5 — без дизеринга кольца на радиальном фоне). CI зеленый.
- Single-file exe: сжатие + удаление pdb → 70 МБ вместо 153 МБ.
- Дизайн: пользователь попросил UI интереснее, «не хуже аудио-программ», расположение не менять; выбрал темную тему. Решение: `Themes/Dark.xaml` (шаблоны стандартных контролов, акцент бирюзовый, метки цветов пальцев), `Themes/HighContrast.xaml` (системные стили) — переключает `ThemeManager` по `SystemParameters.HighContrast`. Темный заголовок окна через DWM.
- UI smoke-тест в CI (`tools/ui-smoke.ps1`, Windows PowerShell + UIA): окно стартует, ввод работает, скриншоты просмотрены. Найдено на экране 1024×768: маленькое превью, наложение чипа на заголовок, перенос текста по буквам → колонки сделаны резиновыми.
