# Changelog

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — [SemVer](https://semver.org/lang/ru/).

## [Unreleased]

### Изменено
- Темная тема окна в стиле аудио-софта: карточки, цветные метки пальцев (как на картинке), сегментный переключатель ориентации, акцентная кнопка «Сохранить», подсветка поля с ошибкой, темный заголовок окна. Только шаблоны стандартных контролов: имена, подсказки и порядок Tab не изменились.
- В режиме высокой контрастности Windows окно автоматически переходит на системное оформление (и обратно без перезапуска).
- Колонки окна тянутся по ширине; над превью показан размер и формат.
- «Проверить обновления» и версия перенесены из шапки в строку состояния (справа); кнопка оформлена как ссылка, Alt+Б и место последней по Tab сохранены. Индикатор состояния под превью убран — он остается в строке состояния.
- Карточки пальцев слегка тонированы цветом пальца вместо цветной полосы слева. Переключатель ориентации растянут на ширину карточки, выпадающие списки одной высоты с полями ввода. «Выбор пути…» стоит справа от поля «Текущий путь» (по Tab — сразу после него). Сводка предупреждений под «Сохранить» убрана: предупреждения объявляются и видны в строке состояния и у полей.

### Добавлено
- Иконка приложения (бирюзовый медиатор с буквой M): у exe, в заголовке окна и на панели задач; логотип в шапке окна (векторный, из `Assets/majormode.svg`). Подзаголовок в шапке убран.
- Ссылка «Поделиться» (Alt+Д) слева в строке состояния: открывает страницу проекта на GitHub в браузере, копирует ссылку в буфер обмена и объявляет результат.
- Кнопка «Проверить обновления» (Alt+Б): обновление из GitHub Releases с подтверждением, проверкой SHA-256, заменой exe и перезапуском; объявление «Программа обновлена». Версия показывается в строке состояния.
- CI публикует GitHub Release `v0.1.<номер сборки>` на каждый push в `main` и проверяет обновление сквозным тестом на Windows.
- Индикатор состояния картинки в строке состояния: «Картинка готова, не сохранена», «Есть ошибки в полях», «Сохранение…», «Сохранено: имя», «Не сохранено», «Изменено, не сохранено». Читается командой чтения строки состояния (NVDA+End, Диктор+End), автоматически не объявляется.
- UI smoke-тест в CI (`tools/ui-smoke.ps1`): запуск exe на Windows, ввод через UI Automation, скриншоты окна и список фокусируемых элементов с именами (артефакт `ui-screenshots`).

## [0.1.0] — 2026-11-07

### Добавлено
- WPF-приложение (MVVM, .NET 10 LTS) для генерации картинок гитарных аккордов.
- Ввод 4 пальцев (лад, струна), полное баррэ первым пальцем (`B`), пропуск пальца `0/0`, поле заглушенных струн (`6`, `6,5`, пусто/`XX`).
- Валидация с текстом ошибок у полей, сводкой и предупреждениями (палец на заглушенной струне).
- Автодиапазон ладов (минимум 5, максимум 7, старт с лада баррэ).
- Ориентация грифа: вертикально / горизонтально; холст 16:9, 9:16 и 4K.
- Три стиля: схематичный, современный темный, реалистичный деревянный.
- Экспорт: GIF (собственный кодер GIF89a, median cut + Floyd–Steinberg), PNG, JPG.
- Санитизация имен файлов по правилам Windows, подтверждение перезаписи, атомарная запись.
- Текстовое описание аккорда для screen reader, объявления через UIA без перевода фокуса.
- Сохранение настроек в `%LOCALAPPDATA%\MajorMode\settings.json` (SchemaVersion 1).
- Тесты xUnit, генератор образцов, GitHub Actions workflow для Windows.
